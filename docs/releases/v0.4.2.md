An explicit, unambiguous feature reference in a main-user prompt now loads a tracked context package outside the Implement skill, including questions, planning, reviews and direct implementation. Relevant knowledge reads retain the package load_id so the existing Context Board can associate source retrievals with that load.

The native userPromptTransformed hook injects bounded context and respects hooks.contextAutoLoad=false. Ambiguous references and child-agent prompts do not trigger reads; failures produce a notice without retries or an untracked fallback. No workflow is started. Local file reads and model comprehension are not recorded.

Validation: focused context and native protocol process tests, package checks and integration tests. These deterministic checks do not claim a new native Copilot model session. Publishing does not modify active sessions or user-installed plugins.
