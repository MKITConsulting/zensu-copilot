# Zensu for Copilot CLI 0.8.1

AI-work checkpoints can now send an explicit review file containing the implemented
summary, acceptance criteria, evidence, limitations and an optional source-system
URL for the immutable result. Use `ai-work checkpoint --review-file <file>` through
the native helper with the report's disclosure scope approved by the user.

The report is validated before submission and frozen in a private receipt for
retries. A changed report creates a new result even at the same commit; previous
human acceptance never carries over. URLs are supplied explicitly and are never
inferred from Git remotes. Metadata-only checkpoints remain supported.

This aligns the reporter with Zensu CLI 0.20.0 and the released review-details API
(backend 0.107.0, frontend 0.151.0). Native identity, the capture deadline, product
and goal-scope requirements, recovery and human-only acceptance remain unchanged.

Validation covers the capture contract, native adapter, package integrity and the
full deterministic CI suite. Fixture tests do not claim live Copilot rendering.
Publication does not update installed plugins or restart active sessions.
