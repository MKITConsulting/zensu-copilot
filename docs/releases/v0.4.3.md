Context packages now put directly relevant evidence first and preserve additional relationships as a separate metadata-only index. Each entry retains its relevance reason and relationship path, and the shared display budget is spent on direct context before additional relationships.

Automatic context guidance and manual retrieval instructions require a concrete unresolved question before fetching an additional source. Selected reads retain the original load_id so the Context Board can associate them with the package load. Additional relationships are not bulk-loaded, and older backends without separate relevance layers remain supported.

Validation: deterministic automatic-context and native protocol fixtures, package checks, integration tests and release CI. These checks do not claim a new native Copilot model session. The release and native marketplace publish the verified package without changing active sessions or installed plugins.
