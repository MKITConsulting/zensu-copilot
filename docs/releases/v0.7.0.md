# Zensu for Copilot CLI 0.7.0

AI-work goals now require an explicitly selected feature within the confirmed
repository product. The feature determines the product; an optional revision
must belong to that feature. Product maintenance and cross-product work remain
available only with an explicit reason.

A rejected or incomplete new goal pauses the previous capture receipt before
validation, preventing later commits from being attached to the old task.
Coding can continue when capture is unavailable. Existing history and human
acceptance decisions are preserved.

Requires Zensu CLI 0.18.0 or newer and the feature-scope backend API introduced
by MKITConsulting/zensu-monorepo#1311 (backend 0.105.0, migration 000624).
Deploy the backend and CLI before updating this plugin.

Validation covers feature/revision scope, capture transitions, native package
integrity, marketplace publication and workflow integration. Fixture tests do
not claim a new provider-backed Copilot conversation. Publication does not
modify installed plugins or active sessions.
