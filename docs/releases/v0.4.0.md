Context retrieval history for the Zensu Context Board.

## Changes

- Load implementation context with `zensu knowledge context-pack --agent copilot` and preserve the returned `load_id`.
- Correlate relevant source fetches with `zensu knowledge get --context-load` so the board can show the declared host, authenticated account and server timestamps.
- Treat receipt failures explicitly. A file reference does not prove a local file read, and retrieval does not prove model understanding.

Requires Zensu CLI 0.13.0 or newer and the backend context-load endpoints. Existing unrecorded CLI reads remain supported.

## Validation

Knowledge-context contract checks and native package/integration tests run before publication, including Linux and macOS CI. This release changes implementation instructions; no new native provider session was executed, and deterministic tests are not native acceptance evidence.

## Update

After publication, update the Zensu marketplace and plugin in Copilot and start a fresh session. Active sessions and local plugin installations are not modified by publishing this release.
