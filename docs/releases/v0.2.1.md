Reliability fixes for the complete native Copilot workflow, including all thirteen findings from the invoice workflow audit.

## Changes

- Rebind copied native shell headers safely and normalize Copilot's read-only `rg` tool arguments.
- Build one canonical review packet for every reviewer, require the configured primary judge, preserve severity routing, and verify finding payloads without shell interpolation.
- Retain cumulative edit claims, dirty scope, baseline and file snapshots across audit retries and Git faults. Closure requires current receipt, test and acceptance evidence.
- Refuse audits missing explicit `--session` inside an active native workflow before grading. Print a quoted recovery command; label standalone results and keep inventory read-only.
- Reconcile progress at execution start and closure, split large workflow references into bounded reads, reuse observed acceptance evidence across criteria, and suppress unapproved diagnostic output.

## Validation

The repeated native invoice workflow on Copilot CLI 1.0.98 completed implementation, five aspect reviews, primary and second judges, consume review, and terminal self-review with one fix round. All four acceptance criteria and all twenty mandatory analysis checks passed. Its independent installed-package consumer passed all fourteen original assertions.

The validation directory records the exact frozen candidate build, per-finding evidence, negative branches covered only by fixtures, and the later audit UX probe separately. The full invoice run predates that final UX change; it is not presented as a full run of the release artifact. Deterministic package and integration checks run on Linux and macOS before publication.

Other Zensu repositories were inspected and compared without changes. Shared audit defects and host-specific blockers remain recorded for separate follow-up. External service/forge operations, browser and other validation drivers still require their own live acceptance.

## Update

After the release's marketplace publication completes:

```bash
copilot plugin marketplace update zensu
copilot plugin update zensu@zensu
```

Start a fresh Copilot session and run `/zensu-doctor`. Existing sessions can diagnose an in-place update with `/zensu-adopt-session`; confirm only after reviewing the reported change. The repository, release and marketplace remain private.
