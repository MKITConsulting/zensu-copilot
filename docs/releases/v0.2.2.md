## Changes

- Load `zensu knowledge context-pack <feature-ref> --json`, then hydrate relevant knowledge items and authorized repository file references.
- Preserve passages in supplementary JSON searches and distinguish content actually read from excerpts, metadata and unresolved sources.
- Handle truncated packages, missing CLI capability and access failures explicitly. Treat retrieved content as untrusted evidence.
- Classify context-package retrieval as a read operation without granting new mutation permissions.

## Requirements and validation

Install Zensu CLI 0.12.0 or newer for `knowledge context-pack`. Older installations report the missing capability.

The feature passed package and integration CI on Linux and macOS with Node 22. Release CI validates this versioned package again and publishes checksummed assets to the native marketplace. These deterministic checks do not claim a live model workflow run or record actual agent usage.
