The first native Zensu release for GitHub Copilot CLI.

## Included

- All 32 Zensu skills, six specialist agents and 11 native hook events.
- Native workflow, evidence, acceptance, review, self-review and session recovery.
- Native Copilot event, tool, approval and transcript handling, with no Claude compatibility layer or runtime dependency.
- Session-trail and the work-order launcher, preserving identity, lease and permission boundaries.
- Explicit in-place plugin update adoption that preserves workflow state.

## Validation

The native implementation passed 420 automated tests and a real Copilot CLI 1.0.98 workflow through acceptance, native review and terminal self-review. A subsequent same-session update/resume completed with the workflow byte-for-byte unchanged. CI also verifies the immutable upstream snapshot and native package on Linux and macOS with Node.js 22.

The live evidence records identify the exact tested builds. Release preparation changes documentation and distribution/CI files; it does not change the plugin runtime. Human plan/browser approvals, external Zensu/forge operations, other validation drivers and backend work-order round trips still require separate live acceptance. Host-specific differences are documented in `docs/parity.md`.

## Install

Download `zensu-copilot-0.2.0.tar.gz`, `build.json` and `SHA256SUMS`, verify the checksums, extract the archive, then run:

```bash
copilot plugin install "$(pwd)/zensu"
```

Restart Copilot and run `/zensu-doctor`. Existing sessions affected by an in-place update can use `/zensu-adopt-session`; apply `--confirm` only after reviewing and accepting the diagnosed update.

Requires Node.js 22+, Bash, Git and authenticated Copilot CLI. Additional workflows require their corresponding Zensu/forge/validation tools. The release and repository are private. The inherited license is FSL-1.1-Apache-2.0.
