# Zensu for Copilot CLI 0.5.0

AI work capture now records the packaged Copilot plugin version and an explicit
work/test purpose. Retries preserve the original metadata; legacy receipts remain
unknown, and human purpose corrections are not overwritten. Explicit validation,
demo and probe goals use test; ordinary product work that includes tests stays work.

Requires Zensu CLI 0.15.0 or newer and a backend containing the AI-work run-metadata
API from MKITConsulting/zensu-monorepo#1254.
Deploy the backend and CLI first. Older installations fail visibly instead of
silently dropping metadata. Human acceptance and revocation remain separate.

Validation: capture/retry/legacy/correction tests, native package checks and
integration tests, plus the actual CLI/capture adapter against an isolated local
backend. These checks do not claim a new provider-backed Copilot conversation.
The published package does not modify active sessions or installed plugins.
