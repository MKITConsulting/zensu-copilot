Automatic work capture through the native Copilot CLI plugin and personal Zensu CLI authentication.

## Changes

- Record an agreed implementation goal in direct mode as well as workflow mode, with a stable task key, objective and criteria version.
- Bind reporting to the native main session and authenticated CLI user; child sessions and overridden selectors cannot claim ownership.
- Submit only a new clean Git HEAD. Private durable receipts preserve retries, duplicate prevention and account/API binding; native agentStop retries an already declared goal.
- Return the exact result review URL. Human acceptance and revocation remain explicit web decisions about the submitted version. A commit, report, merge or passing test never accepts a result.
- Upload no code, diffs, transcripts, prompts, file lists or token usage.

Requires Zensu CLI 0.11.0 or newer and the authenticated capture API. Missing login or prerequisites remain visible incomplete capture.

## Validation

A guided native Copilot CLI 1.0.100 probe with local Ollama and Zensu CLI 0.11.0 verified authenticated goal declaration, a native edit and clean commit, result submission and idempotent repetition. A second commit was submitted exclusively by the real agentStop hook, with no model-issued checkpoint. Independent server read-back verified the exact versions, artifacts and reporting identity, with no human decision. Both dashboard scopes displayed the first result correctly.

The frozen runtime matches the release preparation. The [native validation report](https://github.com/MKITConsulting/zensu-copilot/blob/main/docs/validation/2026-10-25-native-ai-work-capture.md) separates the successful guided integration probe from earlier quota-blocked and failed local-model attempts. It does not certify the small model for autonomous coding or every auxiliary Copilot feature. Complete package and integration checks run on Linux and macOS before merge and again before publication.

## Update

After the release and its marketplace publication complete:

```bash
copilot plugin marketplace update zensu
copilot plugin update zensu@zensu
```

Start a fresh Copilot session and run `/zensu-doctor`. The package targets Copilot CLI; no IDE capture or IDE Stop behavior is claimed.
